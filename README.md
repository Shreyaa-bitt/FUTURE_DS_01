# FUTURE_DS_01 – Sales Data Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing retail sales data using Power BI to uncover key business insights such as revenue trends, top-performing products, and regional performance.

## 🎯 Objective

The goal is to help stakeholders:

* Understand sales trends over time
* Identify high-performing products
* Analyze city-wise performance
* Support decision-making for future growth

## 🛠 Tools Used

* Power BI
* Excel / CSV Dataset

## 📊 Dashboard Features

* Monthly revenue trend analysis
* Product-wise performance
* City-wise sales distribution
* Interactive filters (Month, City, Product)
